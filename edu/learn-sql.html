1. What SQL does

SQL reads and transforms tabular data. Three queries cover most work:

  • SELECT — pick columns
  • WHERE — filter rows
  • GROUP BY — aggregate/summarize
SELECT region, SUM(revenue) AS total
FROM sales
WHERE year = 2024
GROUP BY region
ORDER BY total DESC;
