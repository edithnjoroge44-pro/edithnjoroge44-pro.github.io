A practical rubric for rating AI outputs (and why it decides who gets hired)

By Edith Njoroge · Software Engineer & AI Domain Expert · 7 min read · ai-eval-rubrics repo

There is a quiet difference between “I can tell when an answer is good” and “I can specify, to a colleague, precisely what makes it good.” Companies hiring people to evaluate AI — to grade generated code, rate model answers, or build error taxonomies — are paying for the second one. That is a skill you can demonstrate, and the artifact is a rubric.

The anatomy of a rubric

A useful rubric is not a single 1–5 scale. It has three parts:

  • Criteria — the dimensions that matter, stated independently (e.g. accuracy, completeness, clarity, citation support).
  • Levels — a small, defensible set of distinct quality bands, each described in observable terms that do not rely on taste.
  • Anchor examples — one real sample per level so a grader can calibrate against concrete cases rather than vibes.

Descriptors beat adjectives

The classic failure is a level description like “good answer.” Two graders will disagree. An anchored level is something like: “Makes the correct factual claim, supports it with a source, and flags any uncertainty about the source’s authority.” That is a checkable condition, and the difference shows up immediately in inter-annotator agreement.

Weighted scoring, not just a single score

Not every criterion deserves equal weight. I make criteria weights explicit and compute a weighted total, then report per-criterion scores so a 3/5 and a 4/4 are distinguishable rather than collapsed into “good.” My harness also runs the rubric as code — so the rubric is not just a document, it is a repeatable rule you can apply to a batch and get consistent, auditable numbers.

Why this matters professionally: building an evaluation rubric and a graded, citation-backed sample is exactly the kind of work evaluation platforms hire for. It is also a transferable skill: the same rubric thinking applies to code reviews, acceptance criteria, and quality gates.

My open-source ai-eval-rubrics repository contains a full rubric library, a runnable scoring harness, and a citation-supported graded sample — and it is honest about what it demonstrates rather than claiming client work.
